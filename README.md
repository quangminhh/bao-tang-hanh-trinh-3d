# Bảo tàng Hành trình 3D — Cuộc đời Chủ tịch Hồ Chí Minh

Bảo tàng số 18 gian dựng bằng three.js, chạy trực tiếp trên trình duyệt: mỗi bảng một chuyên đề kiểu tạp chí có ảnh tư liệu, đồ vật kể chuyện, giọng đọc thuyết minh, hướng dẫn viên AI chạy trên máy người xem (WebGPU), đố vui và hộ chiếu hành trình.

Thực hiện: SutraLab. Ảnh tư liệu: Wikimedia Commons (giấy phép ghi trên từng ảnh). Vật liệu, bầu trời, mô hình đồ vật: Poly Haven (CC0). Giọng đọc: VieNeu-TTS (Apache 2.0) và Microsoft Edge TTS, lưu ở kho bao-tang-hanh-trinh-am.
